# FoodShare AI Documentation

Static React + Vite + Tailwind documentation site for **FoodShare AI** (MoFPI hackathon project).

## Run locally
1. Extract the ZIP.
2. Open `foodshare-ai-documentation` in VS Code.
3. Open a terminal (Terminal > New Terminal).
4. `npm install`
5. `npm run dev`
6. Open the localhost URL shown by Vite (usually http://localhost:5173).

## Production build
`npm run build` creates `dist/`. Preview it with `npm run preview`.

## Edit content
All text lives in `src/data/project.json`.

## Placeholders to replace
`GITHUB_URL_PLACEHOLDER` (project.json), `REFERENCE_URL_PLACEHOLDER` (References, in `src/App.jsx`), `SITE_URL_PLACEHOLDER` (`public/sitemap.xml`), `[ADD HERE]` (test steps, ETA card).
Charts marked "Illustrative Demo Data" use sample numbers, not project results.
